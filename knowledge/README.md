# knowledge/

Aquí va la teoría que el coach usa para explicar el *porqué*. Cada archivo es un MD con este frontmatter:

```
---
title: Nombre del tema
tags: estrategia, medio-juego, peones   # para ./coach kb
fase: opening | middlegame | endgame | todas
---
```

Carpetas:
- `estrategia/`: planes, estructuras y piezas
- `tactica/`: motivos tácticos
- `finales/`: técnica de finales
- `aperturas/`: tu repertorio y las ideas de cada apertura
- `psicologia/`: reloj, tilt, rutina

Para agregar algo, pégale al coach un resumen, un link o tus notas y dile "guárdalo en knowledge". Lo resume con sus palabras y lo archiva. También puedes crear los MD a mano.
